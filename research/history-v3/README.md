# Annual historical research snapshot library

52 annual snapshots; 10167 source regions passed original-byte, year, license-notice, GEOS and native geometry checks. Historical accuracy NOT_VERIFIED; formal approval NOT_GRANTED. This is a world/continent-scale research reconstruction, not complete global coverage or certified borders. Some Features are cultural areas rather than states. Source QA is not independent historical adjudication.

Each year is available only for its explicitly declared snapshot year; no adjacent-year carry. Blank-name map scaffolding and incompatible geometry are excluded. Known manual holds remain HOLD. See SOURCE_REVIEW.json and each year's research review.

Source: André Ourednik and Historical Basemaps contributors, pinned revision da7a4b735ecef70aebdc9c73e409d8a2500d50f3. The separate annual DATA collections are distributed under GNU GPL version 3; each includes the verbatim preferred GeoJSON, upstream README, year index, full source/LICENSE and provenance. Extracted wrappers retain original Feature values and dated modification notices. No warranty. The referenced Cliopatria primary collection remains separately CC BY 4.0.
